# Desarrollo de Interfaces - UD2

## Control de dispositivos Domésticos con Interfaces Naturales

El objetivo del ejercicio es implementar interfaces naturales para que el usuario pueda manejar un mando de televisión mediante instrucciones visuales y sonoras, además de que pueda visualizar los cambios de volumen en una interfaz.
